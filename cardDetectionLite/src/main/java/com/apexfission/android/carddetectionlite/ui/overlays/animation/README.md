# `com.apexfission.android.carddetectionlite.ui.overlays.animation`

Source set: `main` · Module: [`:cardDetectionLite`](../../../../../../../../../../docs/README.md)

## Contribution

Exposes animated detection bounds and a Canvas scope for custom drawing.

## Responsibilities and boundaries

AnimatedDetectionBounds groups coordinates, progress, effects, and tracking metadata. AnimatedDetectionCanvas makes them available to drawing code. DetectionAnimationConfig configures state helpers without changing detection results.
