# :app documentation

The sample application demonstrates live camera detection and recorded-video simulation. It is the integration/test bench for `:cardDetectionLite`, `:tfmodel`, and `:permissionsCompose`, not a reusable library.

- [Running and extending the sample](guide.md)
- [Testing](testing.md)
- [Package map](packages.md)

The application ID is `com.apexfission.android.cardDetectionTest`; the Kotlin namespace is `com.apexfission.android.carddetectiontest`. It uses minSdk 28, compileSdk/targetSdk 36, and toolchain 17. See [build configuration](../build.gradle.kts).
